## 🧩 Systems & Apps

<sub>Private projects: the code isn't public, so here's what each one does.</sub>

### 🤖 AI Prospecting CRM
Multi-company outbound CRM for teams prospecting local businesses. The AI runs the outreach and learns from every lead.
- Lead pipeline with daily queues (today, overdue, auto inbox) and full funnel tracking
- AI diagnosis of the lead's website and messages written in the lead's own language
- AI learns from won and lost deals (RAG) to sharpen the next approach
- WhatsApp, e-mail and phone outreach, CSV/JSON lead import with deduplication
- Quotes and proposals exported to PDF, with currency and taxes by country
- Admin area for the team, release notes, video tutorials, and installable as a PWA

`Next.js` `React` `TypeScript` `Tailwind CSS` `Supabase` `PostgreSQL` `OpenAI` `Resend` `Vercel` `PWA`

### 🗳️ Supporter Registration PWA (political campaign, DF)
Installable app for a federal deputy campaign's street team.
- Supporter registration in the field, **works offline**
- Admin view to follow the whole team's work in one place

`React` `Vite` `Tailwind CSS` `Supabase` `PostgreSQL` `PWA` `Vercel`

### 🐄 AgroTech Manager <sub>(collaboration)</sub>
API and dashboard for beef cattle management.
- Corral, weighing, health records, lots, pastures and veterinary stock
- OAuth2 + JWT authentication, interactive map with Leaflet, PWA front end
- Optional AI assistant with Google Gemini, tests running on GitHub Actions

`Python` `FastAPI` `SQLAlchemy` `PostgreSQL` `Alembic` `JWT` `Leaflet`

### 🥟 Crocante! <sub>(game in development)</sub>
Cozy management game set in a Brazilian *pastel* shop.
- Visual-novel style 2D conversations with customers at the counter
- Four 3D toon-shaded cooking stations: register, dough, filling and frying
- Full day loop: orders, delivery with rating, payment, end of day and an upgrade shop

`Unity 6` `C#` `Blender` `.NET`
